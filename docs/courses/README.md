## I. Introduction

**Course Notes** is a dedicated space for systematizing foundational and advanced knowledge in Artificial Intelligence (AI), compiled into concise and highly structured lectures. 

The project aims to build an open knowledge base serving both personal reference and review needs, as well as providing an intuitive resource for the community, especially those beginning their journey in Data Science and AI.
